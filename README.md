# 🕶️ TapImage — My First AR Lens Experience ✨

> 🎓 A beginner AR/VR project built for my college's extracurricular subject

---

## 📖 Overview

**TapImage** is a fun, beginner-level **Augmented Reality (AR)** lens built using **Snapchat Lens Studio** 🎨📱. This is my **first-ever AR project**, created as part of the **AR/VR extracurricular subject** at college — a small step into the exciting world of immersive tech! 🚀

---

## 🧩 About the Project

This project is a simple AR filter/lens made for **Snapchat** 👻. It walks through the core building blocks of AR lens creation — setting up a scene, working with the camera, and adding basic interactions to bring the lens to life.

## 🎯 Purpose

This project was created to:
- 🧠 Understand the basics of AR lens creation using Lens Studio

- 🙌 Get hands-on, practical exposure to AR/VR concepts taught in class

## 🛠️ Tools & Technologies Used

- 🕶️ **Snapchat Lens Studio** — for designing and building the AR lens

---

## 🚀 How to Open the Project

1. ⬇️ Download and install [Snapchat Lens Studio](https://ar.snap.com/lens-studio)
2. 🖥️ Open Lens Studio
3. 📂 Load the project file `Pract1.esproj`
4. ▶️ Preview the lens using the built-in simulator, or test it live on the Snapchat app via a paired device 📱
